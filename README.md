# GC2USB — GCコントローラー → Switch 2 変換アダプター

ゲームキューブ（GC）コントローラーを、Nintendo Switch 2 に有線 USB で接続して使うための変換アダプターです。
RP2040-Zero が GC コントローラーを読み取り、HORI ポッ拳コントローラー互換の USB ゲームパッドとして振る舞います。

- ファームウェア最終版: **v1.2**（2026-11-09 完成、Switch 2 実機で動作確認済み）
- 2台を同時に挿しての利用も可能（USB シリアルが基板ごとに異なるため、ホスト側で別々に認識されます）

## 動作モード

| 起動方法 | モード | LED |
|---|---|---|
| 通常の USB 接続 | Switch モード | 青 |
| GC の Start を押しながら USB 接続 | PC モード | 緑 |

- LED は起動中とパッド未検出の間はゆっくり明滅し、パッドを検出するとモード色で点灯します。
- PC では通常は Switch モードのまま使えます（Windows からは「POKKEN CONTROLLER」として認識されます）。
- PC モードは名乗りが同じまま、L/R のアナログ値が追加の軸（Rx / Ry）として出る PC 専用モードです。レポート形式が異なるため、このモードで Switch に接続しても使えません。
- シリアル（CDC）は両モードとも無効です。

## マッピング

- A / B / X / Y・両スティック・十字キー: そのまま
- Start → ＋（コンボ判定のため約 100ms 遅れて発火）
- 肩ボタンはプロファイル切替式（起動時は「汎用」、L+R+Z 約1秒長押しで切替）
  - 汎用: L → L / R → R / Z → ZR
  - スマブラ寄り: L → ZL / R → ZR / Z → R
- 同時押しコンボ（発火中は元の入力を抑制）
  - Start + Z → −
  - Start + 十字キー下 → キャプチャー
  - L + R + Start 約1秒長押し → Home
- スティックは半径方向ゲインで外周までフルレンジ化しています（`GAIN_MAIN_PCT` 160 / `GAIN_C_PCT` 170、スケッチ先頭で調整可能）

## 必要なもの

- Waveshare RP2040-Zero
- GC コントローラーポート（メス）— 本作ではジャンク Wii 本体から取り外した純正ポートを使用
- 1kΩ 抵抗（DATA のプルアップ用）
- GC コントローラー

## 配線

GC コネクタ正面（中央のベロを挟んで）:

- 上段 左→右: 1 = 5V（未接続）/ 2 = DATA / 3 = GND
- 下段 左→右: 4 = GND / 5 = 未使用 / 6 = 3.3V
- 外側シェル: シールド（GND）

| 信号 | 接続先 |
|---|---|
| DATA（2番） | RP2040-Zero **GP29**。DATA–3.3V 間に **1kΩ** のプルアップ |
| 3.3V（6番） | 3V3 |
| GND（3・4番、シェル） | GND |
| 5V（1番） | 未接続（振動モーター用。本作では振動なし） |

## ビルド方法

- Arduino IDE 1.8.19 + Earle Philhower 版 RP2040 コア
- ボード: Waveshare RP2040 Zero
- USB Stack: **TinyUSB** を選択
- `gc_switch_adapter/gc_switch_adapter.ino` を開いて書き込み

## ケース

`case/` に 3D プリント用 STL が入っています（PLA、白で印刷）。

- `GC2USB_1.stl`: 本体トレイ
- `GC2USB_2.stl`: カバー（アーチ部でポートを押さえる）
- `GC2USB_3.stl`: 前面パネル（円形開口 Ø17.5 にポートのフランジが嵌る）

接着剤なし、前面パネルのはめ込み（スナップフィット）で組み立てられます。
外形は約 23 × 48.5 mm です。

## 制限事項

- 振動なし（5V 線を接続していないため）
- ジャイロ / NFC には非対応（GC コントローラー側に無いため）
- Switch 2 ではドック経由の有線接続が前提です
